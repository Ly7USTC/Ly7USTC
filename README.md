## Hi, I'm Yuan Li 👋

I hold a PhD in Statistics from **Imperial College London**. My research is on estimation methods and limit theorems of stochastic processes. This page collects some code behind my research projects.

### 🔬 Research code

| Project | What it does | Code |
|---|---|---|
| **[GMM estimation of BSS processes](https://github.com/Ly7USTC/gmm-bss)** | Simulation and generalised-method-of-moments estimation of gamma-kernel Brownian semistationary processes, with an application to volatility indices. | Python · R |
| **[Time-varying OU processes](https://github.com/Ly7USTC/tvou)** | Exact simulation of gamma-driven Ornstein–Uhlenbeck processes and jump-filtering / bipower-variation estimators of a time-varying drift coefficient. | Python · R |
| **[Multidimensional quantiles](https://github.com/Ly7USTC/Multidimensional-quantile)** | Cone quantiles of bivariate random vectors for normal, uniform, empirical and discrete distributions, β-Vorob'ev quantiles, and the convex-level-sets property behind elicitability (MSc project). | R |

PhD work is joint with Mikko S. Pakkanen and Almut E. D. Veraart; MSc project supervised by Tobias Fissler.
